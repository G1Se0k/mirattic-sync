# Mirattic Sync Documentation Map

- `CLAUDE.md` — Claude Code top-level rules
- `docs/README.md` — repository overview
- `docs/progress.md` — current phase, completed work, tests, known issues, next task
- `docs/architecture/plan.md` — approved architecture decisions
- `docs/protocol/rest.md` — REST API contract
- `docs/protocol/websocket.md` — WebSocket protocol and sync rules
- `docs/platform-policy/README.md` — provider policy verification workflow
- `docs/claude/` — lightweight task-specific guidance modules

The canonical project state lives in architecture/progress/protocol docs.
The `docs/claude/` files should reference those documents instead of duplicating them.
