## 4. 이용과 제공
- 위 목적 외에는 쓰지 않는다. 판매, 광고, 제3자 제공을 하지 않는다 (Chrome Web Store Limited Use 준수).
- 다른 사용자에게 보이는 범위: 친구에게는 표시 이름과 공개 범위 설정에 따른 시청 정보, 같은 방 멤버에게는 표시 이름·방 참가 여부·방의 재생 상태·채팅.
- 처리 위탁 / 국외 이전: 서버·DB·백업은 운영자가 직접 관리하는 대한민국 소재 서버. 모든 통신은 Cloudflare, Inc.(미국) 네트워크를 거침 (통신 내용, 접속 IP)

## 5. 이용자의 권리
- **공개 범위**: 앱의 "공개 범위"에서 시청 콘텐츠를 친구에게 보일지 정할 수 있다 (기본: 친구). 재생 위치는 친구에게 보이지 않고 같은 방 멤버만 방의 재생 상태로 본다.
- **메시지 삭제**: 내가 보낸 채팅 메시지는 언제든 지울 수 있다. 내용은 서버에서도 지워지고, 모든 멤버의 채팅에는 "삭제된 메시지입니다" 자리표시만 남는다. 방 호스트도 방의 메시지를 지울 수 있다.
- **계정 삭제**: 앱의 "계정 삭제"에서 Mirattic 계정 비밀번호를 다시 입력하면 즉시 삭제된다. Mirattic Sync의 계정, 친구·요청·차단 관계, 방 멤버십, 내가 보낸 모든 채팅 메시지, 내가 하거나 받은 신고, 내가 보낸 피드백이 함께 지워지고, 내가 호스트인 방은 닫힌다. 다른 기기의 로그인도 즉시 끝난다. 데이터베이스 백업(매일, 운영 서버에만 보관)에는 삭제 후 최대 8일 동안 남았다가 백업과 함께 지워진다. 서버가 멈춰 있어 정리 작업이 돌지 못한 기간이 있으면 서버가 다시 켜진 뒤 첫 정리 때 지워진다
- **차단·신고**: 친구 목록과 방 멤버를 신고할 수 있고, 차단하면 서로 친구·방에서 빠진다. 채팅 메시지 신고 버튼은 없다 (이전에 접수된 메시지 신고는 복사본과 함께 보관).

## 6. 보안
- 운영 환경의 전송은 HTTPS / WSS만 사용한다.
- 비밀번호와 로그인 토큰은 Mirattic 계정(Mirattic Auth)이 해시로만 저장한다. Mirattic Sync 서버는 비밀번호도 토큰도 저장하지 않고 중계만 한다. 기기에는 refresh token 자체를 둔다: Extension은 브라우저를 다시 열어도 로그인이 유지되도록 Chrome 프로필의 확장 저장소(`storage.local`, 확장 페이지만 읽을 수 있음, 암호화되지 않음)에 둔다. 로그아웃하면 지우고, Mirattic Auth는 토큰을 쓸 때마다 바꾸며 재사용이 보이면 그 로그인 전체를 끊는다(결정 68, 82).
- 서버 로그에 비밀번호, 토큰, 재생 정보, 메시지·신고 내용을 남기지 않는다 (신고는 ID만 기록).
