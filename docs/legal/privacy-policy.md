## 3. 수집하지 않는 정보
- YouTube·Netflix·라프텔 등 영상 서비스의 비밀번호, 쿠키, 세션 토큰, 로그인 정보
- 영상 자체 (중계·다운로드·저장하지 않음. 각자 자기 계정으로 직접 재생)
- 지원하는 영상 페이지 외의 방문 기록
- 광고 식별자, 분석·추적 정보

## 4. 이용과 제공
- 위 목적 외에는 쓰지 않는다. 판매, 광고, 제3자 제공을 하지 않는다 (Chrome Web Store Limited Use 준수).
- 다른 사용자에게 보이는 범위: 친구에게는 표시 이름과 공개 범위 설정에 따른 시청 정보, 같은 방 멤버에게는 표시 이름·방 참가 여부·방의 재생 상태·채팅.
- 처리 위탁 / 국외 이전: `[ ]` (호스팅, Cloudflare — Phase 10에서 확정)

## 5. 이용자의 권리
- **공개 범위**: 앱의 "공개 범위"에서 시청 콘텐츠·재생 위치를 친구에게 보일지 정할 수 있다 (기본: 콘텐츠는 친구, 위치는 같은 방에서만).
- **메시지 삭제**: 내가 보낸 채팅 메시지·리액션은 언제든 지울 수 있다 (모든 멤버의 화면에서 사라짐). 방 호스트도 방의 메시지를 지울 수 있다.
- **계정 삭제**: 앱의 "계정 삭제"에서 비밀번호를 다시 입력하면 즉시 삭제된다. 계정, 로그인 정보, 친구·요청·차단 관계, 방 멤버십, 내가 보낸 모든 채팅 메시지, 내가 하거나 받은 신고가 함께 지워지고, 내가 호스트인 방은 닫힌다. 다른 기기의 로그인도 즉시 끝난다. 데이터베이스 백업(매일, 운영 서버에만 보관)에는 삭제 후 최대 8일 동안 남았다가 백업과 함께 지워진다 `[ ] 기간 확정`
- **차단·신고**: 친구 목록, 방 멤버, 채팅 메시지에서 신고할 수 있고, 차단하면 서로 친구·방에서 빠진다.
- 열람·정정 요청: `[ ]` 연락처로 (앱에서 표시 이름·공개 범위는 직접 확인 가능)

## 6. 보안
- 운영 환경의 전송은 HTTPS / WSS만 사용한다.
- 비밀번호와 refresh token은 해시로만 저장한다. Desktop은 refresh token을 OS 키체인에, Extension은 브라우저를 닫으면 지워지는 저장소(`storage.session`)에 둔다.
- 서버 로그에 비밀번호, 토큰, 재생 정보, 메시지·신고 내용을 남기지 않는다 (신고는 ID만 기록).
