# Laftel 정책

확인 날짜: 2026-09-28 (Phase 7 시작 시)

## 확인 방법
- **사용자가 직접 확인** (2026-09-28): 라프텔은 제3자 개발자를 위한 정책을 따로 두고 있지 않다. 약관 위험은 Netflix보다 낮다고 판단했고, Netflix와 같은 방식(실험 기능, 기본 꺼짐)으로 진행하기로 결정
- Claude는 이 세션에서 라프텔 약관 원문을 열람하지 못함 (도구 권한 확인 오류). **약관 조항 원문과 개정일은 아직 이 문서에 없음** → 스토어 공개 전 채워야 함 (아래 "불확실한 항목")

## 공식 API 여부
- 없음 (공개 playback / 제어 API, 제3자 확장 정책 없음, 사용자 확인)

## 허용된 플레이어 제어 범위
- 명시적 허용 없음 → 불명확 → 보수적 구현: Netflix와 같이 사용자가 위험 안내를 보고 직접 켬

## 금지 동작 (구현하지 않음)
- 라프텔 내부 JS API / page-world 스크립트 호출, 네트워크 요청 가로채기, 스트림·자막 접근
- DRM 관련 모든 것, 화면 캡처, 재전송
- 페이지 DOM에 UI 삽입, 플레이어 가림. 예외 (2026-09-30 결정 87, 사용자 결정): 초대·합류 요청·일시정지 요청 알림과 그 응답 버튼(수락/거절)을 영상 오른쪽 위에 30초 표시 (플레이어는 조작하지 않음). 사이드 패널이 닫혀 있을 때만(열리면 모두 지움), 전체화면이면 전체화면 요소 위, 아니면 화면에 보이는 가장 큰 `<video>` 위. 읽는 것: 전체화면 여부, `<video>`의 화면 위치·크기
- 쿠키·세션·프로필 정보 읽기
- 사용자가 없는 탭 자동 재생·자동 이동

## 로그인 / 세션 취급
- 각 사용자가 자기 라프텔 계정으로 브라우저에서 직접 로그인. Mirattic은 아무것도 읽거나 저장하지 않음

## 재전송 금지
- 서버로 가는 것은 콘텐츠 ID(URL `/player/<작품 ID>/<에피소드 ID>` → `"작품/에피소드"`)와 탭 제목, 재생 상태 메타데이터뿐

## 계정 / 회선 제한
- 멤버마다 자기 라프텔 계정과 이용권 필요. 동시 재생 제한(요금제별 기기 수)을 우회하는 기능 없음
- 볼 수 없는 회차(이용권 없음, 지역)는 볼 수 없음. 우회 안내 없음

## 구현 원칙 (결정 50–52, `plan.md`)
- **기본 꺼짐.** (2026-09-29 결정 81로 바뀜) `https://laftel.net/*`는 설치 때 받는 `host_permissions`, 켜고 끄는 것은 확장 설정. 꺼져 있으면 laftel.net에 코드를 넣지 않고, 지금 탭이 laftel.net인지만 봄(켤지 안내, 서버로 보내지 않음)
- content script는 manifest에 없음(`registration: 'runtime'`). side panel이 **따라가는 라프텔 탭 하나에만** `scripting.executeScript`
- 켜는 곳: 설정의 "실험 기능 · Laftel 제어", 라프텔 방 첫 입장 팝업. 개발자 정책이 없고 허용된 기능이 아니며 계정이 제한될 수 있음을 보여줌
- 읽는 것: URL의 작품·에피소드 ID, 탭 제목, `<video>`의 재생 상태
- 제어: 재생 / 일시정지 / **seek** (`<video>`). Netflix의 M7375 같은 알려진 차단이 없어 YouTube와 같이 seek함. 실제 플레이어에서 문제가 확인되면 Netflix처럼 `seekable = false`로 전환 (`bridge.ts` `SEEKABLE` 한 줄)
- 광고: 감지하지 않음 (켜기 화면에서 "광고가 나오는 재생은 지원하지 않습니다")
- 채팅은 side panel 안

## 법률 검토 체크리스트
`netflix.md`의 표와 같은 항목(약관 계약, 제3자 계약 위반 유도, 기술적 보호조치, 정보통신망법, 개인정보, Chrome Web Store, 상표)을 라프텔에도 적용. 법률 자문 아님 — 스토어 공개 전 변호사 검토 필요.
라프텔 약관 조항 원문이 기록되지 않아 약관 항목은 **미확인**.

## 불확실한 항목
- **약관 조항 원문·개정일 미기록** (사용자 확인 결과만 있음). 자동화 도구·프로그램 사용 금지, 서비스 변경·방해 금지 조항이 있는지 원문으로 확인 필요
- **플레이어 URL 형식 `/player/<작품>/<에피소드>`는 실제 사이트로 확인하지 않음** (가짜 페이지 E2E만). 다르면 `providers/laftel.ts`, `packages/types` `LAFTEL_ID`, 서버 `LAFTEL_ID`를 함께 수정
- 탭 제목 형식 ("작품 - 라프텔"로 가정), `<video>` 하나인지, `currentTime` 쓰기가 라프텔 플레이어와 어긋나지 않는지 미확인
- 광고 회차 존재 여부 미확인
