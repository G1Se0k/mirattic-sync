1.3.0 2026년 10월 9일최신

새 기능

  • 방을 만들 때 창이 먼저 열려 방 제목(20자까지), 최대 인원(2~8명), 공개 · 비공개를 정할 수 있습니다. 호스트는 방 안의 "방 설정"에서 바꿀 수 있습니다(인원은 지금 들어와 있는 사람 수보다 적게 줄일 수 없습니다).
  • 공개 방 목록이 생겼습니다. 방 목록의 지구본 버튼으로 열어 방 제목이나 영상 제목으로 찾고, 자리가 있는 방에 바로 참가할 수 있습니다(내보내졌거나 차단 관계인 멤버가 있는 방은 보이지 않습니다). 공개 방에서는 방 제목 · 영상 · 호스트 이름 · 인원이 모든 사용자에게 보입니다.
  • 방 안에서 친구가 아닌 멤버를 누르면 친구 코드 없이 바로 친구 요청을 보낼 수 있습니다. 채팅의 닉네임을 눌러도 같은 메뉴가 열립니다.
  • 설정 → 개인정보 → "친구 요청 받기"에서 같은 방 멤버의 요청을 받을지(누구나), 친구 코드로만 받을지 고를 수 있습니다.
  • 공개 방에서 영상을 보고 있는 친구에게 "합류 요청"을 누르면 요청 없이 바로 그 방에 들어갑니다. 방이 가득 찼으면 알려 주고, 그 방에 들어갈 수 없는 경우(내보내짐 · 차단)에는 지금처럼 요청이 갑니다.

개선

  • 방이 없을 때 "방 생성 · 공개방 탐색 · 코드로 입장" 큰 버튼 세 개가 보입니다.
  • 방을 나간 사람의 채팅도 "나간 사용자" 대신 이름으로 보입니다.
  • 메인 화면의 친구 요청 목록이 친구 목록 아래로 옮겨졌습니다.

1.2.1 2026년 10월 5일

개선

  • 스크롤바가 옆 공간을 차지하지 않고 내용 위에 얇게 떠서, 직접 스크롤할 때만 잠깐 보입니다. 보이는 동안 잡고 끌 수 있습니다. 설정 화면에서는 보이지 않습니다.

1.2.0 2026년 10월 4일

새 기능

  • 설정에서 지금 버전을 보고 "업데이트 확인"으로 새 버전을 받을 수 있습니다. 준비되면 "지금 업데이트"로 바로 적용합니다.
  • 방 정원이 8명(호스트 포함)으로 정해졌습니다. 방 화면의 "멤버" 칸이 자리 수와 "3 / 8"을 보여 주고, 가득 차면 입장과 초대가 막힙니다.
  • 멤버 목록을 접고 펼 수 있습니다. 멤버를 누르면 호스트 넘기기 · 내보내기 · 신고를 아이콘으로 고릅니다.

개선

  • 화면을 새로 다듬었습니다. 홈은 방 · 친구를 묶음으로 보여 주고, 방 줄에 입장 · 나가기 아이콘, 친구의 합류 요청은 손 아이콘이 붙습니다. "지금 보는 영상" 카드에서 바로 내 방으로 가거나 새 방을 만듭니다.
  • 설정을 계정 · 같이 보기 · 화면 · 실험 기능 · 개인정보 · 정보 묶음으로 정리했습니다. 로그인 화면도 새로 꾸몄습니다.
  • 방에서 "목록으로"를 누르면 호스트도 방을 닫지 않고 목록으로 갑니다. 방을 닫으려면 방 닫기 아이콘을 누르세요.
  • 타임스탬프는 내 브라우저가 방 영상을 보여 줄 때만 찍고 누를 수 있습니다. 호스트가 방 영상이 아닌 다른 화면을 보고 있으면 멤버는 찍을 수 없고, "호스트가 영상을 고르고 있습니다."로 알려 줍니다. 호스트가 눌러 이동할 수 있는 시각은 색으로 구분됩니다.
  • 영상 변경 기록에 채널 이름이 붙습니다("호스트가 영상을 바꿨습니다: 채널 - 제목").
  • 채팅에 호스트의 재생 · 일시정지 · 넘기기 기록이 더 이상 쌓이지 않아 대화가 깔끔해졌습니다.
  • 멤버의 화면이 조금 늦게 따라온 경우(넘긴 자리에 덜 도착했거나 새 영상이 늦게 시작한 경우) 자동으로 다시 맞춥니다.
  • 안 읽은 메시지 수 배지와 채팅 음소거를 없앴습니다.

수정

  • 멤버 목록을 열 때 채팅이 위로 올라가던 문제를 고쳤습니다.
  • 홈을 열 때 "아직 방이 없습니다"가 잠깐 보이던 문제를 고쳤습니다.
  • 서버가 응답하지 않을 때 오래 기다리지 않습니다.

1.1.1 2026년 10월 3일

새 기능

  • 보내기 버튼 옆의 "타임스탬프 찍기"로 지금 장면을 남길 수 있습니다("○○님이 12:34에 스탬프를 찍었습니다"). 호스트가 누르면 그 장면으로 이동합니다.
  • 표시 이름이 Mirattic 계정 이름을 따릅니다. 계정에서 이름을 바꾸면 패널로 돌아올 때 바로 반영됩니다.

개선

  • 채팅의 시각은 그 영상에서만 이동합니다. 다른 영상의 시각을 눌러도 엉뚱한 곳으로 가지 않습니다.
  • YouTube 믹스 · 재생목록으로 보는 방에서 멤버는 목록 없이 영상만 엽니다. 다음 영상은 호스트를 따라갑니다.
  • 호스트를 따라 영상이 바뀌어도 멤버의 탭을 앞으로 끌어오지 않습니다.

수정

  • 패널을 다시 클릭할 때 방 화면이 새로 그려지던 문제, 채팅 줄 높이가 들쭉날쭉하던 문제를 고쳤습니다.
  • YouTube 재생바를 끌면 기록이 한 줄로 남습니다. 늦게 읽힌 제목도 나중에 고쳐집니다.
  • 다른 창으로 옮긴 탭도 계속 인식합니다.

1.1.0 2026년 10월 3일

새 기능

  • 재생 속도도 맞춥니다. 호스트가 1.5배로 보면 멤버도 1.5배로 봅니다(YouTube · Netflix · 라프텔).
  • 패널을 별도 창으로 분리할 수 있습니다("창으로 분리" / "사이드 패널로 돌아가기").
  • "동기화 끄기"로 방에서 나가고 오프라인이 됩니다. 패널을 다시 열면 켜집니다.
  • "인식할 탭"에서 동기화할 탭을 직접 고르거나, "활성 탭 자동 따라가기"를 켤 수 있습니다.
  • 영상 없이 방을 먼저 만들 수 있고, 호스트가 방의 사이트를 바꾸면 멤버에게 확인을 받습니다.
  • 설정에 글자 크기(80–150%), "피드백 및 버그 리포트", "계정 정보 수정"이 생겼습니다.

개선

  • 호스트가 방을 나가면 방이 닫히고 멤버에게 알려 줍니다. 호스트 연결이 끊기면 30초 기다렸다가 닫습니다.
  • YouTube Premium 미니플레이어에서도 동기화됩니다.
  • 패널은 가장 최근에 연 창 하나에만 열립니다.
  • 이미 같은 방에 있는 친구에게는 합류 요청 버튼이 나오지 않습니다.
  • 방 화면의 "마지막 보정" 표시를 없앴습니다.

1.0.1 2026년 10월 1일

새 기능

  • 초대 · 합류 요청 · 일시정지 요청이 영상 위 알림으로 뜹니다. 패널이 닫혀 있거나 전체 화면이어도 바로 답할 수 있고, 남은 시간(30초)이 막대로 보입니다.
  • 한 번에 한 기기에서만 접속됩니다. 다른 기기에서 접속하면 이전 기기는 멈추고 "여기서 계속"을 고를 수 있습니다.

개선

  • 보낸 합류 요청이 남은 시간과 함께 카드로 보이고, 거절되면 알려 줍니다.
  • 친구 목록에 YouTube 채널과 제목만 보이고 재생 위치는 보이지 않습니다.
  • 영상이 없는 페이지로 옮기면 남아 있던 합류 요청 알림을 정리합니다.
